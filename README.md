# 聊天截图生成器

纯前端的聊天截图制作工具。聊天内容和上传素材保存在当前浏览器，不会上传到服务器。

## 功能

- 支持单聊、群聊、浅色与深色主题、自定义状态栏、输入栏和聊天背景。
- 支持文字、图片、语音、通话、撤回、系统消息、链接、视频、文件、转账、红包、名片和位置消息。
- 支持微信样式行内表情、引用回复、手填语音秒数与转文字。
- 支持头像、名片头像、地图截图和聊天壁纸的拖动缩放取景。
- 支持消息拖动排序、指定位置插入、多选删除、批量换发送人和批量平移时间。
- 支持批量脚本、可复用脚本片段、场景模板、联系人与常用群组素材库。
- 支持实时预览、定位编辑、截图范围、滚动位置和自定义输出尺寸。
- 支持下载 PNG、复制 PNG、当前页面截图暂存盘与批量 ZIP，以及超长聊天分段导出 ZIP。
- 支持浏览器内多项目、最近 10 个恢复点和项目 JSON 导入导出。
- 支持按内容、发送人和类型定位消息；所有对话可主动使用精简编辑行，200 条及以上默认开启。
- 可选跟随系统时间、充电、勿扰、聊天未读数和听筒播放提示；默认关闭，不改变旧项目外观。
- 顶部 GitHub 入口可打开项目源码仓库。

## 快速使用

1. 在“设置”中选择单聊或群聊，编辑成员、主题和聊天外观。
2. 在“消息”中添加内容，选择发送人、消息类型和时间。
3. 在“预览”中确认截图范围和效果。
4. 使用“复制 PNG”或“导出 PNG”；需要继续编辑时，在“项目”中保存或导出 JSON。

## 项目与备份

顶部“项目”用于新建、切换、重命名、复制和删除本地项目。切换项目、恢复版本、重置或导入 JSON 前会自动创建恢复点。

项目 JSON 包含聊天内容、设置和引用的媒体，可用于换浏览器或换设备继续编辑。联系人素材库、常用群组和撤销历史不包含在项目 JSON 中。

所有项目都保存在当前浏览器。清除站点数据、切换浏览器或更换访问地址前，请先导出 JSON 备份。

## 批量脚本

在“效率工具 → 批量脚本”中粘贴聊天内容：

```text
10:30
我：马上到
阿花：[图片]
我：[语音 8s] 在路上
我：[转账 52.00] 午饭
阿花：[红包 88.00] 周末快乐
[系统 拍一拍] 阿花|我
```

支持中文或英文冒号。未匹配的昵称会自动创建成员；应用前可以预览错误，并选择追加、插入或替换消息。

## 导出

- 手机屏幕和聊天长图共用实时预览画布，预览缩放不会改变 PNG 尺寸。
- 支持 `1×–4×` 倍率、自定义输出宽高、长图起止消息和当前滚动位置。
- 导出前会检查截图范围、媒体加载、字段完整性和画布尺寸。
- 单张 PNG 任一边不能超过 16384 像素；超长聊天可按消息边界导出为 ZIP。
- 复制 PNG 需要 Chrome 允许图片剪贴板权限；权限不可用时仍可下载 PNG。

当前只保证桌面版 Google Chrome。Safari、Firefox 和其他浏览器不在回归范围内。

## 本地运行

要求 Node.js 22.12 或更高版本。

```bash
npm ci
npm run dev
```

开发服务器默认运行在 `http://localhost:4173`。

## 验证

```bash
npm run check
npx playwright install chrome
npm run test:e2e
npm run benchmark
```

| 命令 | 用途 |
| --- | --- |
| `npm run check` | ESLint、Vitest 和生产构建 |
| `npm run test:e2e` | Chrome 端到端、无障碍和视觉回归测试 |
| `npm run benchmark` | 500/1000 条消息的渲染与导出基准 |
| `npm run test:visual:update` | 人工确认界面变化后更新视觉基准 |

端口被占用时可指定测试端口：

```bash
E2E_PORT=43129 npm run test:e2e
BENCHMARK_PORT=43130 npm run benchmark
```

## 构建与部署

```bash
npm run build
```

构建结果位于 `dist/`，部署为静态文件即可，不需要后端或数据库。

部署到 GitHub Pages 等仓库子路径时设置：

```bash
VITE_BASE_PATH=/chat-screenshot-generator/ npm run build
```

部署到域名根路径时无需设置 `VITE_BASE_PATH`。线上环境应使用 HTTPS，确保剪贴板和编辑锁等浏览器能力可用。

## 数据存储

| 数据 | 存储位置 |
| --- | --- |
| 当前草稿 | `localStorage` |
| 项目、恢复点和上传媒体 | IndexedDB `chat-screenshot-generator` |
| 联系人与常用群组 | IndexedDB |
| 最近使用表情 | `localStorage` |
| 脚本片段 | `localStorage`，独立于项目 JSON |
| 截图暂存盘 | 当前页面内存，最多 20 张或 100 MB，刷新后清空 |
| 撤销与重做历史 | 当前页面内存，刷新后清空 |

当前草稿结构版本为 `3`，IndexedDB 版本为 `2`，项目 JSON 格式版本为 `1`。修改这些版本前需要同时设计数据迁移。

同一网站同时只允许一个编辑页面，避免多个标签页互相覆盖草稿。关闭原编辑页后即可在另一个页面继续。

## 代码结构

React 19 + TypeScript 6 + Vite 8，使用 CSS Modules、dnd-kit、html-to-image 和 fflate。

| 目录或文件 | 职责 |
| --- | --- |
| `src/App.tsx` | 工作台、弹窗和导出流程编排 |
| `src/app/` | 草稿类型、reducer、撤销历史和默认数据 |
| `src/components/editor/` | 设置、成员和消息编辑器 |
| `src/components/chat/` | 预览与 PNG 共用的聊天画布 |
| `src/components/projects/` | 本地项目与恢复点界面 |
| `src/hooks/` | 项目、媒体和导出流程 |
| `src/services/` | 本地存储、项目文件、媒体处理和图片导出 |
| `e2e/` | Chrome 端到端与视觉回归测试 |
| `benchmarks/` | 长对话性能和导出内存基准 |

新增消息类型或字段时，需要同步检查类型、reducer、迁移、编辑表单、画布、质量检查、项目文件、媒体清理和测试。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 换浏览器或端口后看不到项目 | 回到原访问地址导出 JSON，再到新地址导入 |
| 提示已在其他标签页打开 | 关闭原编辑页后重试 |
| 本地保存失败 | 保持页面打开，先导出 JSON，再检查浏览器存储空间 |
| PNG 提示媒体加载失败 | 等待加载后重试，或重新上传对应素材 |
| PNG 尺寸过大 | 使用分段 ZIP、降低倍率或缩小截图范围 |
| 视频或音频无法播放 | 检查文件编码；推荐使用 H.264 MP4 和浏览器支持的音频格式 |
